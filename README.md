# DMV Simulator

A pixel-art game about waiting in line at the DMV. Earn points on "productive"
distractions — read the newspaper, text a friend, sneak off for a bathroom
break — while your Patience, Hunger, Bladder, and Phone Battery all drain in
real time. Starting on day 2, line-cutters try to steal your spot, so you'll
need to hold your ground. Reach the front and the DMV closes anyway — come
back tomorrow for a longer line and a worse day. It's a pure high-score chase.

**[▶ Play now](https://1n5an1ac.github.io/Dmv/)**

## Controls
Arrow keys to move · `X` use · `Z` text · `C` guard your spot. On mobile, a
transparent on-screen D-pad and action buttons appear automatically.

## Running locally
It's a single self-contained `index.html` — no build, no install, no
dependencies. Just open the file in a browser.
